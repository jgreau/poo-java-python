# javafx-base

Proyecto base JavaFX 21 (Maven, modular): un `Stage` con una `Scene` que contiene un `Label`.

## Requisitos
- JDK 21
- Maven 3.9+ (o el Maven integrado de IntelliJ)

## Ejecutar
```
mvn javafx:run
```
En IntelliJ: abrir la carpeta (`File > Open` sobre `pom.xml`) y ejecutar `HelloApplication`.
